# Research Assistant: working notes

- This is a proof of concept. Keep it simple and keep it honest: the idea under test is in the README ("Proof of concept"). Prefer changes that make that idea easier to see over new features.

- `public/` is the app and is edited directly. `source/research-assistant.artifact.html` is the original single-file export, kept for reference; `npm run split` re-creates `public/index.html`, `styles.css` and `app.js` from it and overwrites edits. The split applies four small named patches to `app.js` (sample-only data loading, sample-data markers, refresh text); if the artifact changes so a patch no longer matches, the script stops and says which.
- There is no server code and no API key. The app never calls Claude. It reaches Claude's runtime only through `window.claude.use("downloads")`, which `public/claude-shim.js` provides. Keep that the single seam.
- Drafts live in the browser's localStorage under `va-research-assistant-v1`. There are no accounts and nothing is shared between people.
- **This repo is sample-only on purpose.** The app loads only `public/data/sample/` (fictional, generated by `scripts/make-sample-data.mjs`). Do not add code that reads other data, and do not paste real quotes, participant details or index files into tests, docs or fixtures. `.gitignore` and `.vercelignore` exclude any `.json` placed directly in `public/data/` as a second guard.
- Sample data: edit `scripts/make-sample-data.mjs`, then `npm run sample`. Tests check that line numbers match the text and that every link points at example.com.
- No dependencies. Tests use Node's built-in runner: `npm test`. Local server: `npm run dev`.
- The app is ~125 KB of one script. Search for a function by name rather than reading it whole.
- Not in this repo: the scripts that built the real index. See the README, "Gaps".
